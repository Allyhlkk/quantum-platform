公式意义（它在回答什么）

Tangle 是 Concurrence 的平方，表示纠缠强度的“能量化”刻度，数值越大纠缠越强。

怎么看图

先看 y=0 阈值线，再看曲线是否上升到 0 以上；红色竖线表示当前 p 位置。

阈值解释

τ > 0 表示检测到纠缠；τ = 0 表示当前点接近可分区域。
