$$W = \frac{1}{2}I - |\Psi^-\rangle\langle\Psi^-|$$ $$\langle W \rangle < 0 \iff \text{entangled}$$
公式意义（它在回答什么）

纠缠见证算符 W 通过期望值判断纠缠：当 <W> < 0 时，说明检测到纠缠。

来历与用途

见证者方法在实验上常见，因为它把“判断纠缠”变成了“测一个可观测量”。适合做直观教学演示。

怎么看图

关键看 <W>=0 阈值线：曲线在 0 下方即判为纠缠。红线对应当前 p，便于点读。
