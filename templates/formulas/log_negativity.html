$$E_N(\rho) = \log_2\left(2N(\rho) + 1\right)$$ $$N(\rho) = \sum_{\lambda_i < 0} |\lambda_i(\rho^{T_B})|$$
公式意义（它在回答什么）

Log-Negativity 用于衡量纠缠强度，E_N=0 通常表示可分态，数值越大表示纠缠越强。

怎么看图

先看 y=0 阈值线，再看曲线是否上升到 0 以上；红色竖线表示当前 p 位置，便于读数。

阈值解释

E_N > 0 表示检测到纠缠；E_N = 0 表示当前点接近可分区域。
